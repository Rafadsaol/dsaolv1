As versões transparentes foram preparadas com a ferramenta de edição de imagens a partir da referência fornecida. Não são vetorização da marca. O arquivo SVG mantém uma imagem raster incorporada; quando houver o vetor original da logo, ele poderá substituir esses arquivos para reduzir o tamanho e melhorar a nitidez em escalas maiores.

A aplicação usa caminhos locais, texto alternativo e proporção preservada por CSS. Não aplicar filtros de cor nem deformar a imagem para fazê-la caber.
